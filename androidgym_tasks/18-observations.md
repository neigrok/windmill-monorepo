# Routine movement staging observations

The combined movement form is a staged value owned by the outer routine draft. One domain Plan
commits entries, new metadata, overrides and aliases together; this keeps Add/Done and Cancel free
of partial catalogue writes. Returning the accepted projection avoids relabeling a completed write
because a later refresh failed.

The store owns admitted save work while the room owns publication. Pinning owner, identity
revision, replica and exact attempt prevents a delayed result from closing another form; exact
attempt cleanup prevents a stale job from clearing a newer busy state. Controlled delayed-admission
tests establish this lifetime boundary without claiming native transaction-failure injection.

Uniform and per-set fields reuse `numberStepperEdit` with `TextFieldValue`, so separator, caret and
composition behavior have one grammar. The approved narrow Load layout measures representable
inline content and keeps its expanded state while focused through valid zero. Native evidence
establishes that scope; it does not approve the postponed Target-summary layout or a new full-width
fallback.

Readouts and storage have different contracts: a raw null Dumbbells count means the implicit two,
not missing metadata. Native observers retain SQL, authenticated GET, event and image evidence
before validation so an observer assertion cannot erase the accepted transaction's readback. Source
and installed-APK identities remain separate across composition, and passing partial captures do
not turn failed setup/tooling runs into whole-run acceptance.
