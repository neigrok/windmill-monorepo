Build Windmill with your AI tools

Updated August 2026

Windmill speaks MCP. Point Claude, Cursor, or Codex at one hosted URL and your agent can build your roadmaps and keep your training log with you. The snippet carries no secret — your browser handles the sign-in.

Claude Desktop Claude Code Cursor Codex any MCP client

What your agent can do

  • Plant a roadmap — start a fresh tree from a goal.
  • Add & connect steps — grow branches and wire the prerequisites between them.
  • Paint with the legend — color nodes by the kinds in your tree.
  • Mark progress — set a step active or done.
  • Read roadmaps — inspect a tree and see what's ready next.

Your training log is on the same URL. An agent can open a workout, log sets, write a brand-new routine and read your history back. What it cannot do is change a routine you already have: that arrives in the app as a typed diff — this line went from 5 × 5 to 5 × 3, this movement leaves and keeps its 41 logged sets — and nothing moves until you tap Apply. Gym's levels are approved separately from Roadmap's.

One exchange, end to end

The training log is the clearest thing this URL is for, so here is the whole of it. Sunday, in your own tool: “Look at my last twelve weeks of bench. Write me a four-week block — heavier triples, and swap the flies for incline work.” Monday, in gym: a proposal waiting on Push A. You read the diff, you tap Apply, you train.

It needs an AI tool of your own that speaks MCP — Claude Desktop, Claude Code, Cursor, Codex, or any other MCP client. If you haven't got one, this is not for you yet, and the log stays free regardless: connecting your log costs nothing, and there is nothing here to buy. No plan gates the training log or these tools, and no checkout in Windmill can complete today.

No keys to paste

First connect opens your browser to approve — no keys to paste. The screen lists exactly what the tool asked for: product by product, and level by level — read, write, delete. A level you didn't grant is a tool it can never see. None of them sees your chats. A tool that asks for nothing in particular is asking for your whole account, deleting included; the screen says so in those words.

Need a static token for a client that can't do OAuth? Sign in, then Connect → Advanced to mint one. A minted key has no levels to pick: it carries the whole account — every product, every level, deleting included — so guard it like a password and revoke it from account settings the moment you don't need it.

Quickstart

Any MCP client — drop this in your config, pointed at https://windmill.works/mcp:

STANDARD mcpServers JSON
{
  "mcpServers": {
    "windmill": { "url": "https://windmill.works/mcp" }
  }
}

Claude Desktop — Settings → Connectors → Add custom connector, name it Windmill, paste the URL:

CONNECTOR URL
https://windmill.works/mcp

Claude Code — one line in the terminal:

TERMINAL — ONE LINE
claude mcp add --transport http windmill https://windmill.works/mcp

Cursor — add to ~/.cursor/mcp.json, then switch it on under Cursor settings → MCP:

~/.cursor/mcp.json
{
  "mcpServers": {
    "windmill": { "url": "https://windmill.works/mcp" }
  }
}

Codex — add to ~/.codex/config.toml and restart:

~/.codex/config.toml
[mcp_servers.windmill]
url = "https://windmill.works/mcp"

Streamable HTTP (MCP 2025-06-18) + OAuth 2.1. There is no SSE transport: a client that speaks only the older SSE protocol can't connect yet.

README

Copy this into your own project so anyone can connect:

# Windmill MCP
One hosted URL, OAuth in the browser — no keys to paste.

{ "mcpServers": { "windmill": { "url": "https://windmill.works/mcp" } } }

Your agent can: plant a roadmap · add & connect steps · paint with the legend · mark progress · read roadmaps · keep a training log.
You approve what it may do — read, write, delete, per product — on the browser screen. It never sees your chats.
