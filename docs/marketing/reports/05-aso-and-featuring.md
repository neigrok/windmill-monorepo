# 05 · Make the three-room iPhone app understandable and findable

**Prepare the iPhone listing against the [launch contract](../strategy.md#launch-contract).** Use a broad
Windmill identity for Roadmap, Journal and Gym, with the builder’s job as the lead demonstration. Try “Pick up your project where you left off” as the headline. Mark a step complete in a
sample project, reopen the tree and show that the same step is still marked complete. Use the actual
native screens and verbs once the candidate supports the sequence. [Public release checks](01-store-readiness.md)

The founder owns a listing worksheet: app name, subtitle, keywords, description, category, screenshots,
preview, storefront and build evidence. Keep Windmill as the umbrella; validate descriptive candidate terms
such as skill tree planner, workout log and private journal against the demonstrated jobs and Apple's
current field rules. Record the chosen wording and observed search terms, not guessed volume or ranking
promises. Read the default listing as a builder, lifter and writer before submission.
[Apple product page](https://developer.apple.com/app-store/product-page/) ·
[App Store search](https://developer.apple.com/app-store/search/)

Audience-specific product pages earn their work when a real Gym, Journal or Roadmap distribution lane
needs different screenshots and a distinct destination. They do not replace the default three-room page.
Use page-level evidence where available before adding more variants. The founder records publication and
page URL separately from drafts; the release owner confirms that each asset matches the candidate.

| Asset | What goes in it | Check before use |
|---|---|---|
| Default iPhone listing | Show Roadmap, Journal and Gym clearly, with one real action per room. Lead with the sample project and completed step, then show writing/retrieval and routine/log/history. | Capture founder-owned data on the candidate. Compare screenshots, subtitle, description and review notes with that version. |
| Launch clip and store link | Show the completion mark after an app restart. End with one invitation to download Windmill on iPhone. | Before distributing the clip, follow the intended storefront link without TestFlight, install the public version and repeat the action. |
| Optional Windmill One copy | Describe one verified paid benefit and the actual billing terms where the offer is available. Keep the primary invitation focused on the free Roadmap action. | Use purchase wording only after a purchase in the iOS app delivers both One access and funding. [Offer verification](04-gym-demo-and-checkout.md) |
| Audience-specific page, if warranted | For example, use a real routine, set and history for a group of lifters referred directly to Gym. | Verify the approved page’s unique URL. Record page-level results where available. [Apple custom product pages](https://developer.apple.com/app-store/custom-product-pages/) |
| Editorial nomination, if warranted | Show how a builder finishes one step and picks up their project on the next visit. Give Apple working review access and indicate the intended release window. | Save the nomination status. Count placements only when observed. [Featuring nominations](https://developer.apple.com/help/app-store-connect/manage-featuring-nominations/nominate-your-app-for-featuring) |

If public review runs long, use “Try Ship v1 on the web” for builders. The release waits for its required scope; only the owner can change that scope. Beta copy names only
the actions in that beta. Android Gym keeps its signed APK route and does not gate iOS.

**First week after release.** Record product-page views and first-time downloads by storefront, source
and reporting window where available. Read those alongside first Roadmap actions and later returns.
Keep unattributed activity visible and prelaunch pilot counts separate. At low volume, investigate
broken routes or misleading screenshots before scheduling a split test. New in-app prompts need an
approved design and an available experiment slot. [Funnel definitions](../funnels.md)
