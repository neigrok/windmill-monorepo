# Running Windmill marketing

Start with [the 90-day plan](strategy.md). The first decision is whether builders come back to a skill tree and lifters come back for a second workout. The November pilots feed an early-December public iOS launch targeting Roadmap on iPhone and Windmill One. The owner has a proposed eight hours a week and zero incremental campaign spend for the first month.
