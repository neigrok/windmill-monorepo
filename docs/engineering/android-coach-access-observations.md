# Android Coach access

`CoachAccess.kt` groups the access stances, and `coach/turn/CoachTurnRefusal.kt` each refusal's words and door. A
refusal names a moment only where the server's `budgetResetsAtMs` does, read in the phone's zone, clock and locale when it
draws; no timer submits work. A retained onboarding answer's typed `account_required` draws the fixed sentence and Sign in.

## Setup chat ownership

The setup greeting is local chat metadata, separate from the conversation's records. Its first accepted question hides the
greeting. An account's initial empty-training decision waits for its first pull and successful owned routine and workout
reads; cached navigation is independent. One room function records deliberate tab choices, and one native picker serves both
photo doors. The capture runner has an explicit empty-training capture-only path; it makes no workout performance claim.

## Photo composer

Photo removal commits its draft reference before publishing the change, so a failed document write leaves the attachment
reachable and retryable. Photo selection remains local until Send and emits only after its reference is durable. The static
close icon uses the approved 20 × 20 source asset and Android's native converter; the thumbnail remains the selected image.

## Draft ownership

The composer owns text entry; Continue flushes its current edit before changing the complete draft. Kept drafts belong to the
existing LocalCoach document under owner/chat. Photo adoption copies to a fresh account filename, then publishes the
destination and removes the phone source in one atomic document write.

Adoption and Continue share one publication and reconciliation helper. A write can throw after rename: successful readback
publishes the result, while an unreadable result retains the copy and an in-memory operation receipt. Recovery consumes that
receipt before a stale visible callback can swap again. Restart reads the already published document directly. Account
transition revisions retire queued adoption even when the same account returns. Account deletion erases kept drafts with the
rest of that owner's archive and fences late writes from the retired owner.
