Canonical screens: routine sheet `813:4935`, plan-only editor `820:5572`, create sheet `814:5104`, settings `816:5410`, and Log `837:14824` / `837:14932`. This is the implementation and acceptance contract. States derive from application data. Preserve working behavior; loading, failure and empty states in Specifications belong to the same contract.

Figma uses Nunito, Baloo 2 and JetBrains Mono as stand-ins for Android system sans/display/mono
roles. Runtime uses native fonts and existing platform tokens. The Screens page owns its frame
inventory; the requirements below cover loading, failure, empty and accessibility states too.

Data and interaction contract:

- A completed local calendar month earns a moment when every Monday-based week intersecting that month contains a finished working session inside the month. The moment is dated to the month’s last day. Across all candidates, each local week keeps one moment: new standing e1RM best, then completed month, then weigh-in; equal-priority ties choose the latest event and then stable identity. Expanded movement facts cover the 12 weeks ending at that event. Record All uses the complete series.
- The session estimate is one shared projection: positive loaded working sets,1–10 reps, exclude rated effort below7, choose the highest estimate; load itself at1 rep, otherwise `load × (1 + reps / 30)`. Missing estimates are absent, not zero. Bodyweight/assisted facts remain signed and formula-free. Log row, moment and record must agree on the same session. The shared progress projection applies this rule; do not infer missing RPE or missing working sets from one top-set point.
- Render an estimate chart only with at least4 eligible sessions spanning at least21 days; exactly4 across3 weeks qualifies. Below that show available best/effort/date/count facts without a plot. Place points by their real dates on a labeled time axis, with visible time since the last session where the selected window includes it. Join e1RM points only across gaps of21 days or less; bodyweight uses7 days. Name longer gaps by their bounding dates on the full chart. Never smooth, project, interpolate missing sessions or draw a rolling maximum. One standing-best point is gold only when that exact point is in view; retain a textual fact so meaning does not depend on color.
- Record pan moves plot content only, starts at the latest end, and preserves pinned axes and window label. Use nominal24dp point pitch when dense while preserving real time positions; equal timestamps share one x coordinate. Native recognition distinguishes horizontal pan from a held scrub and yields vertical movement to page scroll. Scrub selects nearest point by x; one readout stays above the plot and wraps at larger text; release restores the latest readout as specified in `678:11277`. A dot is a readable session fact, not another route for correcting sets. Provide chronological accessible point labels and Earlier session/Later session actions.
