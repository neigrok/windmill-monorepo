# Project instructions

## Phone layouts — reach is not optional

Read `guidelines/thumb-reach.md` before drawing any phone screen, and follow it without being
asked: **controls at the bottom, guidance centred in the middle band, identity on top.** Never
leave a top-anchored stack with dead space below the last button, and never put a primary or
destructive button inside a card mid-scroll — pin it to the bottom band. This has been corrected
more than once; treat it as canon, not a preference.

## Palette

A product room is entered by *scope*, never by value: `data-brand="<product>"` plus
`data-theme="light|dark"`, and the product's own token file on top. Never type a hex on a board.
Check `consistency.md` before trusting any product-folder copy of a token file.
