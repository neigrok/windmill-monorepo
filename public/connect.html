Build Windmill with your AI tools

Updated July 2026

Windmill speaks MCP. Point Claude, Cursor, or Codex at one hosted URL and your agent can plant and tend your roadmaps with you. The snippet carries no secret — your browser handles the sign-in.

Claude Desktop Claude Code Cursor Codex any MCP client

What your agent can do

  • Plant a roadmap — start a fresh tree from a goal.
  • Add & connect steps — grow branches and wire the prerequisites between them.
  • Paint with the legend — color nodes by the kinds in your tree.
  • Mark progress — set a step active or done.
  • Read roadmaps — inspect a tree and see what's ready next.

No keys to paste

First connect opens your browser to approve — no keys to paste. It can't share roadmaps, delete them, or see your chats.

Quickstart

Any MCP client — drop this in your config, pointed at https://windmill.works/mcp:

STANDARD mcpServers JSON
{
  "mcpServers": {
    "windmill": { "url": "https://windmill.works/mcp" }
  }
}

Claude Desktop — Settings → Connectors → Add custom connector, name it Windmill, paste the URL:

CONNECTOR URL
https://windmill.works/mcp

Claude Code — one line in the terminal:

TERMINAL — ONE LINE
claude mcp add --transport http windmill https://windmill.works/mcp

Cursor — add to ~/.cursor/mcp.json, then switch it on under Cursor settings → MCP:

~/.cursor/mcp.json
{
  "mcpServers": {
    "windmill": { "url": "https://windmill.works/mcp" }
  }
}

Codex — add to ~/.codex/config.toml and restart:

~/.codex/config.toml
[mcp_servers.windmill]
url = "https://windmill.works/mcp"

Streamable HTTP + OAuth 2.1, with an SSE fallback at /sse for older clients.
